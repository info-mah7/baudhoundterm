---
name: Windows desktop
description: Keyboard-first ways to do common things on a Windows desktop
protocols: vnc
---
Prefer the keyboard on Windows: keys always land, while small icons and buttons are easy to miss
and the click check often refuses them. Click only when no key will do.

- Open an app: `key win`, `type` its name (notepad, calculator, settings, file explorer), `key enter`.
  Never aim at taskbar or Start-menu icons.
- Settings: `key win+i`. File Explorer: `key win+e`.
- Go to a folder in File Explorer: `key ctrl+l` (the address bar), `type` the full path with enter.
  The address bar shows the current folder's name (e.g. "This PC"), so a click on it is hard to check.
- New folder in File Explorer: `key ctrl+shift+n`, `type` the name with enter.
- Calculator: type the sum, e.g. `type 1234*5678` then `key enter`, and read the result. Do not
  click the digit buttons.
- Save in an editor: `key ctrl+s`; in the Save dialog the file name field has focus: `type` the full
  path (e.g. C:\Users\me\file.txt) with enter. If asked to replace, read the dialog before answering.
- Notepad on Windows 11 opens files as tabs in a window that may already hold other people's tabs.
  Before typing, check the title or active tab shows the file you mean; after saving, check the
  tab's name and that its unsaved mark is gone.
- Forms: `key tab` moves between fields. For a dropdown, give it focus and type the first letters
  of the option (or use the arrow keys), then `key enter`; do not click options in an open list.
  Tick a checkbox with `key space` once it has focus.
- Close only the windows and tabs you opened yourself. Anything that was open before you started
  belongs to the user: leave it as it is, even if it is in your way (switch to your own window).
- Close a window: `key ctrl+w` closes a tab or document window in most apps; to close the app, use
  its X at the top right or `key alt+f4` (which asks for approval first).
- Before reporting text, numbers or versions, read them closely: zoom, or use ocr_read where it is
  offered, and quote exactly what is shown.
- After every step, check the new screenshot: did the window, field or text you expected appear?
