# Contributing

Bug reports, patches and corrections are welcome: open an issue or a pull request on
https://github.com/info-mah7/baudhoundterm.

## Licence of contributions

A patch you send is licensed under Apache-2.0, as section 5 of LICENSE says, unless you state
otherwise in writing when you send it.

Code taken from elsewhere must carry a licence compatible with Apache-2.0, and its notice goes in
THIRD-PARTY-NOTICES (generated by `helpers/third_party_notices.py`) or NOTICE.

## Names in the code

The product is BaudHoundTerm. The solution, projects and namespaces still use its working name,
Quarterdeck (`Quarterdeck.sln`, `Quarterdeck.App`, `Quarterdeck.Core`); they are the same thing.

## Building

See "Build" in README.md. Windows 11 to run it; it builds on Linux with the .NET SDK and
`-p:EnableWindowsTargeting=true`.
